## Ce sur quoi je travaille

- **Détection d'intrusions par machine learning** : entraîner des modèles de classification sur des jeux de données de trafic réseau étiqueté
  et les comparer à des règles de détection classiques.
- **Analyse de trafic** : aller plus loin que Wireshark avec des scripts qui automatisent le repérage des comportements suspects.
- **Sécurité de l'IA** : attaques adversariales, empoisonnement de données, fuite d'informations par les modèles.
